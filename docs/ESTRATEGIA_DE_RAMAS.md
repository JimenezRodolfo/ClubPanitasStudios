# Estrategia de ramas - Escape Room 3D

- main: versión principal y estable del proyecto.
- Dev: rama de desarrollo e integración.
- Feature_PlayerMovement: movimiento del jugador.
- Feature_Interaction: interacción con objetos.
- Feature_Animation: animaciones.
- Feature_Puzzle: lógica de rompecabezas.

Las ramas Feature deben crearse desde Dev.
